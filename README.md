# Mechanoid Rex

Mechanoid Rex is a custom Generator Rex character add-on for Minecraft Bedrock. It allows players to transform their body parts into massive mechanical weapons and gear using a futuristic tech menu. Features include the Slam Smack (huge mechanical fists for heavy ground pounding and mining), the BFS (Big Fat Sword) for slashing enemies with high damage, and Punk Busters (giant heavy boots for super jumping and shockwave impacts). The plugin includes custom sci-fi sound effects, orange glowing nanite particle trails, and unique transformation animations.

## Install

1. Download the plugin JAR file from the releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock server.
3. Restart the server to load the plugin.

## Use

1. Open the futuristic tech menu using the designated command or item.
2. Select the desired mechanical weapon or gear to transform your body parts.
3. Use the transformed parts to perform special attacks and abilities.
